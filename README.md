# Social_Network

Кроссплатформенное приложение социальной сети: клиент на **.NET MAUI** (Windows + Android) и серверная часть на **ASP.NET Core** с базой данных **SQLite** и real-time обменом сообщениями через **SignalR**.

Проект реализует полный функционал социальной сети: регистрация и вход, публикации с фотографиями и текстовые заметки, теги и отметки пользователей, лента публикаций, лайки, комментарии с ответами, избранное, подписки (в том числе с заявками для закрытых профилей), личные сообщения в реальном времени, поиск и фильтрация, отчёты и экспорт данных в Excel.

## Возможности

### Профиль и аккаунт
- Регистрация и вход по электронной почте.
- Настройка профиля: логин, описание, аватар.
- Смена пароля, изменение email и логина.
- Параметры приватности: закрытый профиль, уведомления.
- Удаление аккаунта вместе со связанными данными.

### Публикации
- Два типа публикаций: **фото-посты** и **текстовые заметки**.
- Одно изображение на публикацию с загрузкой на сервер.
- Хэштеги (вырезаются из текста и хранятся отдельно, отображаются чипами).
- Отметки пользователей в публикациях (@упоминания).
- Удаление своих публикаций.

### Лента и взаимодействие
- Общая лента и лента подписок.
- Сортировка по дате и по популярности (убывание/возрастание).
- Истории (stories) за последние 24 часа.
- Лайки, комментарии с поддержкой веток (ответы на комментарии).
- Сохранение публикаций в избранное.
- Подписки и отписки, заявки на подписку для закрытых профилей.
- Режим онлайн-статуса и «последний раз в сети».

### Поиск
- Поиск пользователей по логину (`@логин`).
- Поиск публикаций по тексту.
- Поиск и фильтрация публикаций по тегам (`#тег`).

### Сообщения
- Личные чаты между пользователями.
- Обмен сообщениями в реальном времени через SignalR.
- Отмена (удаление) отправленных сообщений.
- Отметка «прочитано», индикатор непрочитанных сообщений.
- Системный чат с уведомлениями: заявки на подписку, одобрение/отклонение, упоминания.

### Отчёты
- Отчёт по популярным публикациям на основе лайков (за весь период или за указанный).
- Отчёт по популярным хэштегам.
- Общая статистика приложения (пользователи, посты, подписки, сообщения, комментарии, лайки).
- Персональный отчёт пользователя.
- Экспорт в **.xlsx** со стилизованными заголовками и автошириной колонок.

## Архитектура

Проект разделён на три части:

- **`Social_Network.Core`** — общие модели данных (`User`, `Post`, `Comment`, `Chat`, `Message`, `Tag`, `Subscription` и т.д.) и DTO. Используется и клиентом, и сервером.
- **`Social_Network.API`** — серверная часть: контроллеры, сервисы, EF-контекст, миграции, SignalR-хаб.
- **`Social_Network`** — клиент MAUI: страницы (Views), модели представления (ViewModels), сервисы для работы с API, конвертеры, вспомогательные классы.

Клиент использует шаблон **MVVM** (CommunityToolkit.Mvvm) и обращается к API по HTTP; real-time чат работает через SignalR.

## Запуск

### 1. Запуск серверной части

```bash
cd Social_Network/Social_Network.API
dotnet run --launch-profile http
```

Сервер запускается на `http://localhost:5043` и `http://0.0.0.0:5043`. Swagger доступен по адресу `http://localhost:5043/swagger` в режиме разработки.

При первом запуске:

- автоматически применяются миграции EF Core,
- создаётся системный аккаунт `__system__` для уведомлений,
- создаётся папка `wwwroot/uploads` для загружаемых файлов.

### 2. Наполнение демо-данными (опционально)

После того как сервер запущен, в отдельном окне PowerShell:

```
./seed.ps1
```

Скрипт создаёт 5 пользователей, публикации, подписки, лайки, комментарии, сохранённые посты и переписку.

### 3. Запуск клиента

```
cd Social_Network/Social_Network
dotnet build -t:Run -f net10.0-windows10.0.19041.0     # для Windows
dotnet build -t:Run -f net10.0-android                  # для Android
```

Для Android-эмулятора хост-машина доступна по адресу `10.0.2.2` (уже учтено в `Constants/ApiConfig.cs`). **Сначала запустите API, потом приложение.**

## Основные эндпоинты API

### Авторизация

- `POST /api/auth/register` — регистрация
- `POST /api/auth/login` — вход
- `POST /api/auth/logout/{userId}` — выход

### Пользователи

- `GET /api/user/{id}` — профиль
- `PUT /api/user/{id}` — обновление профиля
- `PUT /api/user/{id}/account` — обновление логина/email
- `PUT /api/user/{id}/password` — смена пароля
- `DELETE /api/user/{id}` — удаление аккаунта
- `GET /api/user/search?query=...` — поиск пользователей

### Публикации

- `GET /api/post/{postId}` — публикация
- `GET /api/post/feed/{userId}?mode=all|following` — лента
- `GET /api/post/user/{userId}?type=0|1` — публикации пользователя
- `POST /api/post` — создание
- `DELETE /api/post/{userId}/{postId}` — удаление
- `GET /api/post/search?query=...` — поиск
- `GET /api/post/tag/{tag}` — поиск по тегу
- `GET /api/post/tags/search?query=...` — автодополнение тегов

### Комментарии, лайки, избранное

- `GET /api/comment/post/{postId}`, `POST /api/comment`, `PUT /api/comment/{id}`, `DELETE /api/comment/{userId}/{commentId}`
- `POST /api/like/{userId}/{postId}`, `DELETE /api/like/{userId}/{postId}`
- `POST /api/savedpost/{userId}/{postId}`, `DELETE /api/savedpost/{userId}/{postId}`

### Подписки

- `POST /api/subscription/follow`, `DELETE /api/subscription/unfollow/{followerId}/{followingId}`
- `POST /api/subscription/request/{requestId}/approve`, `POST /api/subscription/request/{requestId}/reject`

### Сообщения и чаты

- `GET /api/chat/user/{userId}`, `POST /api/chat`
- `GET /api/message/{chatId}`, `POST /api/message`, `DELETE /api/message/{messageId}`
- SignalR-хаб: `/hubs/chat`

### Отчёты

- `GET /api/report/top-posts?from=&to=`
- `GET /api/report/top-tags`
- `GET /api/report/stats`
- `GET /api/report/user-stats/{userId}`
- `GET /api/report/export/{userId}`

## Работа с изображениями

- Загружаемые файлы сохраняются в `Social_Network.API/wwwroot/uploads`.
- Сервер возвращает относительный путь вида `/uploads/{guid}.jpg`.
- Клиент (`MediaHelper.Resolve`) подставляет к относительному пути адрес API — это позволяет корректно отображать картинки и на ПК, и на Android.
- Внешние ссылки (`http(s)://...`) отдаются как есть.

## Отчёты и экспорт

Экспорт отчётов формируется в формате `.xlsx` средствами собственного генератора OpenXML (`Helpers/ExcelExporter.cs`) — без сторонних библиотек. Файл содержит:

- лист **«Отчёт пользователя»** — ключевые показатели выбранного пользователя и указанный период;
- лист **«Популярные хэштеги»** — топ тегов по количеству использований.

На ПК используется системный диалог сохранения файла, на Android файл попадает в папку «Загрузки».
