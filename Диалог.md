# Диалог по проекту Social_Network (MAUI + ASP.NET Core)

> Этот файл — полная выжимка рабочего диалога. Если контекст чата сжат — читать отсюда,
> чтобы восстановить, что уже сделано и что осталось. Обновляется по ходу работы.

## О проекте
- Курсовая: соцсеть. Клиент — .NET MAUI (`net10.0`, таргеты Windows + Android),
  MVVM на CommunityToolkit.Mvvm. Сервер — ASP.NET Core + EF Core 10 + SQLite, SignalR (чат).
- Запуск на Android-эмуляторе (VS 2026), хост доступен по `10.0.2.2:5043`.
- Загрузка картинок — на сервер в `wwwroot/uploads`, отдаётся через статику.
  `MediaHelper.Resolve`/`MediaUrlConverter` подставляют хост к `/uploads/...`.
- Важно (CLAUDE.md): нигде не светить имя автора. Русские комментарии в коде — оставлять.

## Ключевые технические решения
- Картинки кросс-девайс: загрузка на сервер + конвертеры URL.
- Один пост — одно фото (таблица PostImage удалена). Хэштеги вырезаются из текста.
- «Последний раз в сети»: `User.LastSeen`, online-статус через `AuthService.SetOnlineAsync`.
- Вход — только по почте.
- Чат realtime — `ChatHub` (SignalR). Удаление сообщений — ПКМ/долгое нажатие + подтверждение.

### 3. Большой список правок (предыдущая итерация):
- Убрана возможность нескольких фото; убрана таблица PostImage в БД (миграция
  `DropPostImagesAddLastSeen`), `.Include(Images)` заменён на `PostTags`.

- Убрано динамическое обновление в сохранёнках.

- Дата/время к сообщениям (`MessageTimeConverter`), переход в профиль по отметке.
- Проверка существующего пользователя; проверка тега `#тег` без пробелов
  (`ValidationHelper.IsValidTag`).
- Кнопка панели тегов/отметок → «Готово» при открытии.
- В отчётах: новые теги, посты без описания показываются тегами
  (`ReportService.TopPostsByLikesAsync`).
- Текущая почта в настройках (бэк отдаёт `Email`).
- Лупа тоньше + отзеркалена; фикс бесконечного обновления ленты.
- Вход только по почте; перепроверены валидации.
- Иконка настроек крупнее; полное отображение фото, замена при повторном выборе.

### 4. Последняя большая итерация (дизайн строго по скринам + баги):
**Критический баг:** падение при открытии чата с новым сообщением и при отправке —
`TouchBehavior` нельзя биндить через `RelativeSource` (это Behavior, не Element).
**Фикс:** создан `MessageItemViewModel` (обёртка над `MessageDto` со своим `DeleteCommand`);
`ChatViewModel.Messages` → `ObservableCollection<MessageItemViewModel>`, `Wrap(...)`;
в `ChatPage.xaml` биндинг `Command="{Binding DeleteCommand}"` напрямую. Проверено — не падает.

**Дизайн (выполнено):**
- Лента: пост в карточке (`Border` AppSurface, RoundRectangle 18); ник+ава отделены
  от поста тонкой линией (`BoxView` Margin 16,0); сторис отделены жирной полоской
  цвета меню (`AppNavAccent`, высота 4).
- Заметка: контейнер цвета фона с обводкой `AppNavAccent` и градиентом из центра
  (`LinearGradientBrush`: фон → #465C3210 → фон).
- Фото: **без оранжевого фона** (Transparent), `AspectFit`.
- Блок лайк/коммент/поделиться: только обводка цвета таб-бара (`AppNavBar`),
  без заливки, нижние углы скруглены сильнее (`RoundRectangle CornerRadius="6,6,18,18"`).
- Чипы: теги — `AppOlive`/белый текст; отметки — `AppSurface`+обводка `AppOrange`.
- Профиль: вкладки выбранная = цвет меню (`#5C3210`), невыбранная = полупрозрачная
  (`#665C3210`); полоска под кнопками; в личном профиле цвета «Мои действия»
  (оранж) и «Редактировать» (олива) поменяны местами; «Поделиться» опущена
  на уровень кнопки настроек.
- Навигация (ПК): выбранный пункт — скруглённый прямоугольник радиус 14;
  у всех кнопок радиус 14 (`PrimaryButton`), кроме «Опубликовать».
- Чат: поле ввода радиус 14 + жирная обводка `AppNavAccent`; фон чата темнее
  (`AppChatBackground` #EFE6CF); «назад»/лупа ближе к концам разделителя.
- Список чатов: строка поиска — жирная обводка `AppNavAccent`, плейсхолдер/лупа
  цвета фона; тонкая линия под поиском; разделитель между чатами от края аватарки
  до конца (`Margin="14,0,0,0"`).
- CreatePost: вкладки выбранная темнее (`#8B4E1C`), невыбранная тан (`#D9C6A5`);
  «Опубликовать» — кремовая с обводкой `AppNavAccent` (pill, радиус 24).
- Настройки: иконки тоньше (StrokeThickness 3); опасная зона отделена красной
  полоской + «Внимание» перед «Удалить аккаунт».
- MyActions: жирная полоска под заголовком (3px, `AppNavAccentSoft`); посты —
  точь-в-точь как в ленте; нижние вкладки выбранная темнее, иконки белые
  (`icon_white_like/comment/saved`).
- Поиск: плейсхолдер/лупа цвета фона, жирная обводка `AppNavAccent`.
- Заглушка аватара: идеальный круг через `EllipseGeometry`-клип (обрезает и фон, и фото),
  тело силуэта касается нижнего края круга.
- Комментарии (PostDetail): «Изм.» → карандаш ✎, «Удалить» → оранжевая кнопка-пилюля.

### 5. Итерация (бейдж сообщений, создание постов, отчёты, вход):
- Фон заметок возвращён на прежний (`AppInput`) в ленте и «Моих действиях» (обводка меню оставлена).
- Кружок непрочитанных сообщений: `Helpers/AppState.HasUnreadChats` + событие; бейдж
  (`Ellipse`) на пункте «Сообщения» в боковом меню (ПК) и на иконке чата в таб-баре (телефон).
  Обновляется при загрузке списка чатов и при загрузке ленты (`FeedViewModel` инжектит `IChatService`).
- CreatePost: кнопка «Отметить» темнее (`#46541F`); выбранные теги и отмеченные люди
  показываются под описанием (после «Готово») в разных строках, разделённые тонкой полоской
  (VM: `HasSelectedTags`/`HasSelectedMentions`/`HasTagsAndMentions`); чипы из панелей убраны.
- Отчёты (ПК): страница во всю ширину — карточки `FlexLayout` (по 2 в ряд на ПК, в столбик на телефоне).
- Проверка периода (`ValidatePeriod`): дата «с» не позже «по» и не в будущем — в `LoadReports` и `ExportData`.
- Excel-отчёт переделан: лист «Мой отчёт» (логин, email, посты, отправленные сообщения,
  лайки получено/поставлено, комментарии, подписки/подписчики, его топ-хэштеги) + период
  (или «за всё время») + лист «Статистика приложения» + публикации + теги. Автоширина столбцов,
  заголовки/важные ячейки покрашены в тему (`ExcelExporter`: стили header/title/label, заливки).
- Бэкенд: `report/user-stats/{userId}` → `UserReportDto` (`ReportService.GetUserReportAsync`).
- Вход: сообщение об ошибке изменено на «Неверная почта или пароль» (было «логин»).
