# Руководство пользователя

## 1. Назначение приложения

Приложение Social Network предназначено для публикации заметок и фотографий, просмотра ленты других пользователей, общения в чатах, поиска профилей и публикаций, управления личным профилем, подписками, комментариями, отметками "нравится", избранным и формирования отчетов.

Приложение работает как клиент-серверная система: пользователь запускает клиентское приложение, а данные сохраняются на серверной части в базе данных. При установке на ПК запуск выполняется через один ярлык.

![[Pasted image 20260630231458.png]]

## 2. Установка и запуск

### 2.1. Установка на ПК

1. Запустите файл установщика `SocialNetworkSetup.exe`.
2. В окне установщика выберите папку установки.
3. Нажмите кнопку продолжения установки и дождитесь завершения.
4. После установки запустите приложение через ярлык `Social Network` на рабочем столе или в меню Пуск.

![[Pasted image 20260630231529.png]]

![[Pasted image 20260630231541.png]]

### 2.2. Первый запуск

При запуске приложения открывается окно входа. Если учетная запись уже создана, введите  email и пароль. Если учетной записи нет, перейдите на экран регистрации.
![[Pasted image 20260630231824.png]]

## 3. Регистрация и вход

### 3.1. Регистрация

1. На экране входа нажмите переход к регистрации.
2. Заполните данные учетной записи.
3. Укажите логин, email, дату рождения, пол и пароль.
4. Подтвердите регистрацию.

После успешной регистрации можно войти в приложение под созданной учетной записью.

![[Pasted image 20260630231715.png]]

### 3.2. Вход

1. Откройте экран входа.
2. Введите email.
3. Введите пароль.
4. Нажмите кнопку входа.

После входа открывается лента публикаций.

![[Pasted image 20260630231639.png]]
## 4. Навигация по приложению

Основные разделы доступны через панель навигации:

- лента публикаций;
- поиск;
- создание публикации или заметки;
- чаты;
- профиль;
- настройки.


![[Pasted image 20260630232044.png]]


## 5. Лента публикаций

В ленте отображаются публикации пользователей. Доступны два режима просмотра:

- все публикации;
- публикации пользователей, на которых оформлена подписка.

Публикации можно сортировать по дате или популярности. Также доступен выбор направления сортировки: сначала новые/популярные или сначала старые/менее популярные.

![[Pasted image 20260630232125.png]]

Для каждой публикации доступны действия:

- поставить или убрать отметку "нравится";
- открыть комментарии;
- сохранить публикацию в избранное;
- поделиться публикацией;
- перейти в профиль автора;
- подписаться на автора или отменить подписку.

![[Pasted image 20260630232143.png]]
## 6. Создание публикации или заметки

Экран создания содержит два режима:

- новая публикация с фотографией;
- новая заметка.

### 6.1. Публикация с фотографией

1. Откройте раздел создания.
2. Выберите вкладку фотографии.
3. Нажмите выбор изображения и укажите файл.
4. Добавьте описание при необходимости.
5. Добавьте хэштеги или отметьте пользователей.
6. Нажмите кнопку публикации.

![[Pasted image 20260630232218.png]]

### 6.2. Заметка

1. Откройте раздел создания.
2. Перейдите на вкладку заметки.
3. Введите текст заметки.
4. Добавьте хэштеги или отметки пользователей при необходимости.
5. Опубликуйте заметку.

![[Pasted image 20260630232239.png]]

### 6.3. Хэштеги и отметки пользователей

Для добавления хэштега нажмите кнопку добавления хэштега, введите название без пробелов и подтвердите выбор. Для отметки пользователя нажмите кнопку отметки, начните вводить логин и выберите пользователя из списка.

![[Pasted image 20260630232306.png]]

![[Pasted image 20260630232323.png]]

## 7. Поиск

Раздел поиска поддерживает несколько вариантов:

- `@логин` - поиск пользователей по логину;
- `#тег` - поиск публикаций по хэштегу;
- обычный текст - поиск публикаций по содержанию.

Если строка поиска пустая, отображаются последние публикации.

![[Pasted image 20260630232337.png]]

![[Pasted image 20260630232354.png]]

## 8. Просмотр профилей

В своем профиле пользователь видит аватар, логин, описание, количество подписчиков, подписок и публикаций. Публикации разделены на фото и заметки.

В своем профиле можно:

- открыть публикацию;
- удалить собственную публикацию в режиме редактирования;
- перейти к своим действиям;
- перейти в настройки;
- поделиться профилем.

![[Pasted image 20260630232405.png]]

При просмотре чужого профиля можно подписаться на пользователя, отменить подписку, открыть его публикации или начать переписку.

![[Pasted image 20260630232419.png]]

Если профиль закрыт, заявка на подписку отправляется владельцу профиля. После подтверждения становятся доступны публикации закрытого профиля.

![[Pasted image 20260630232457.png]]

## 9. Комментарии и ответы

Чтобы открыть публикацию полностью, нажмите на карточку публикации или кнопку комментариев. На экране публикации можно читать комментарии, добавлять новый комментарий и отвечать на уже существующие комментарии.

Собственные комментарии можно редактировать или удалять в разделе "Мои действия".

![[Pasted image 20260630232519.png]]

## 10. Мои действия

Раздел "Мои действия" содержит три вкладки:

- понравившиеся публикации;
- мои комментарии;
- сохраненные публикации.

В этом разделе можно управлять своими действиями: убрать лайк, удалить публикацию из избранного, открыть публикацию, перейти к профилю автора, редактировать или удалить собственный комментарий.

![[Pasted image 20260630232533.png]]

## 11. Чаты

В разделе сообщений отображаются существующие переписки. Список чатов сортируется так, чтобы последние переписки были сверху.

### 11.1. Создание переписки

1. Откройте раздел сообщений.
2. Введите логин пользователя в строку поиска.
3. Выберите найденного пользователя.
4. Откроется чат с выбранным пользователем.

![[Pasted image 20260630232551.png]]

### 11.2. Отправка сообщений

В чате можно отправлять текстовые сообщения, прикреплять изображения, просматривать историю переписки и искать сообщения по тексту.

![[Pasted image 20260630232604.png]]

### 11.3. Отмена отправки сообщения

Свое сообщение можно удалить из переписки. Для этого выберите свое сообщение и подтвердите удаление. После удаления сообщение исчезает из истории.

![[Pasted image 20260630233747.png]]

### 11.4. Системные уведомления

В приложении могут отображаться системные сообщения, например уведомления о заявках на подписку. В таких сообщениях доступны действия подтверждения или отклонения заявки.

![[Pasted image 20260630233825.png]]

## 12. Настройки

Раздел настроек содержит переходы к настройкам аккаунта, профиля, приватности и отчетов.

![[Pasted image 20260630233835.png]]

### 12.1. Настройки аккаунта

В настройках аккаунта можно изменить логин, email и пароль. Для смены пароля требуется указать текущий пароль и новый пароль.

![[Pasted image 20260630233850.png]]

### 12.2. Настройки профиля

В настройках профиля можно изменить описание и аватар. Для аватара выбирается изображение с устройства.

![[Pasted image 20260630233903.png]]

### 12.3. Приватность

В настройках приватности можно сделать аккаунт закрытым. При закрытом аккаунте новые пользователи отправляют заявку на подписку, а доступ к публикациям появляется после подтверждения заявки.

![[Pasted image 20260630233925.png]]

### 12.4. Выход и удаление аккаунта

В настройках доступен выход из учетной записи. Также пользователь может удалить аккаунт. Удаление аккаунта является необратимым действием и требует подтверждения.

![[Pasted image 20260630233950.png]]

## 13. Отчеты и экспорт

Раздел "Отчеты и статистика" показывает:

- статистику аккаунта;
- количество полученных и поставленных лайков;
- количество полученных и оставленных комментариев;
- количество сообщений в чатах;
- количество публикаций;
- популярные хэштеги.

Отчет можно сформировать за все время или за выбранный период. Для выбора периода включите переключатель "Указать период", задайте даты начала и окончания, затем нажмите "Обновить отчет".

![[Pasted image 20260630234014.png]]


Для выгрузки отчета нажмите "Экспортировать в Excel". На ПК появится окно выбора места сохранения файла. Экспортированный файл содержит лист со статистикой пользователя и лист с популярными хэштегами.

![[Pasted image 20260630234033.png]]

## 14. Возможные проблемы и способы решения

Если приложение не входит в аккаунт или не загружает данные, проверьте, что серверная часть запущена вместе с приложением. При установке через установщик запуск выполняется автоматически через общий ярлык.

Если не загружается изображение, проверьте формат выбранного файла и попробуйте выбрать другое изображение.

Если отчет не формируется за период, проверьте, что дата начала не позже даты окончания и не находится в будущем.

Если изменения профиля не отображаются сразу, обновите страницу или перезапустите приложение.
