вот смотри, это исходная потоновка задачи:
Исходные данные: личные данные пользователей, медиафайлы.
Обеспечить хранение данных. Предусмотреть выполнение следующих возможностей:
создание и настройку личного профиля (фотография, имя, описание профиля, личные
данные, параметры приватности и т.д.); публикация контента в свой профиль (заметки,
посты с фотографиями и т.п.); отметка других пользователей в своих публикациях;
добавление тегов/хэштегов к публикациям; просмотр ленты публикаций других
пользователей с возможностями выставления отметок «нравится», написания
комментариев (с возможностью отвечать на предыдущие) и сохранения публикаций в
избранное; управление своими комментариями, отметками «нравится» и списком
избранных; просмотр профилей других пользователей; подписка на профили других
пользователей; поиск профилей по имени; поиск и фильтрацию публикаций по
тегам/хэштегам; создание чата между пользователями с возможностями отправлять
сообщения, отменять отправку сообщений, просматривать историю переписки.
Реализовать возможности просмотра, поиска, сортировки и фильтрации необходимой
пользователю информации, предоставить возможности добавления, удаления и обновления
всей хранимой информации. Осуществить формирование отчетов установленной формы, в
том числе и статистических: отчет по наиболее популярным публикациям на основании
отметок «нравится» за весь/указанный период, отчет по наиболее популярным
тегам/хэштегам на основании количества использований, отчет по количеству подписок,
сообщений в чатах, комментариев, отметок «нравится». Обеспечить экспорт данных.
Обеспечить организацию лаконичного адаптивного интерфейса приложения. Реализовать
соответствующую иерархию классов, осуществить работу с информацией. Разработать
руководство пользователя и программиста.

весь проект пишется на MAUI и ASP.NET Core
